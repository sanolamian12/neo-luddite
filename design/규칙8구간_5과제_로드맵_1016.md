### 과제 4 — A9 기여 원장 (import-credigraph — 답변 경로 아님)

- 지침 A9: "공용 승격 → 기여 원장 기록, 철회 시 검색 제외 + 기여 취소". 현재 승격만 ✅(0043), 원장 연결 없음. 합격: **승격 → 원장 +1, 철회 → 검색에서 사라지고 원장 −1, 운영에서 1건 실연**.
- 착수 전 확인: ① 기여·정산 모델 메모(운영 흐름 6단계: 기여 = RAG 존속 기간, 정산 = 수익% × 기여 비율) ② 기존 ledger 테이블·코드가 있는지 `grep -rn "ledger" backend frontend supabase` ③ 10/9 작업 메뉴 `design/다음세션_프롬프트_1009_이후_작업메뉴.md` 의 S3(D-B 모델: 제안서 비식별·불변 제출본·이벤트 이력·저자≠검토자·철회) — **이번엔 장부 범위(승격·철회 ↔ 원장)만**, 관리자 검토 새 모델 전체는 6장 향후 계획.
- **규칙 8 주의**: 철회 = KB3 검색 제외는 검색 결과를 바꾼다. 그러나 대상은 세무사가 승격한 가르치기 사례(공용 KB3 의 일부)뿐이고 평가 문항 답에는 쓰이지 않는다 — 그래도 운영 실연(철회 1건)은 **회신 뒤**에 한다. 회신 전에는 마이그레이션(사용자 실행)·API·화면까지.
- ⚑ 마이그레이션 번호·스키마는 사용자가 터미널에서 적용한다(auto mode 차단). 마이그레이션 파일과 적용 명령을 보여 주고 기다린다.
- 프론트 변경이 응답 모양(Zod)을 바꾸면 프론트 먼저.
- 끝: 지침 A9 행 · 장부 P6 · 이 파일 진행 기록.

### 과제 5 — A8 가르치기 검색 확장 + A10 문장 대조 집계

- **A8**(코드 = rule8-1016, 재임베딩 운영 쓰기 = 회신 뒤): 지침 "R5: `kb3_store.py` 임베딩 텍스트 확장(결론·예외 포함) + 재임베딩. 저장 시 `law_select` 로 `card.law_articles` 채움". 합격: 결론 문장으로 검색해 해당 사례가 1위 · 답변에 조문 배지. 로컬에서 임베딩 텍스트 함수와 저장 시 조문 채우기까지 만들고, **재임베딩은 로컬 dry-run(몇 건이 바뀌는지)** 만. 운영 쓰기는 회신 뒤 사용자 실행.
- **A10**(import-credigraph): 지침 "운영 답변 문장 추출 → 세무사 문장별 대조 → 집계·환류. 인프라 ✅(정지 스냅샷·`/audit/pool`·검수 보드). frontend-v3에서 경로가 살아 있는지 확인. 대조 결과를 집계하는 화면이나 스크립트 추가". 합격: 운영 대화 1건이 스냅샷 → 검수 보드 → 문장 대조 → 집계에 나타남. 회신 전에도 해도 된다(답변 경로 아님).
- 둘 다 끝나지 않으면 A10 을 먼저 끝내고(배포 가능) A8 은 브랜치 상태로 남긴다.
- 끝: 지침 A8·A10 · 장부 P5·P7 · 이 파일 진행 기록 · **다섯 과제 마감 정리**(아래 표를 다 채우고 지침 §6-4 에 "규칙 8 구간 5과제 끝 — 회신 반영 세션이 할 일: rule8-1016 병합·배포 목록" 을 적는다).
