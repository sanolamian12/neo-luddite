R2 원칙 (§6, 세무사 피드백 10/10 — 다시 묻지 말고 이대로)
- 가정은 보수적으로 하고, 가정 문장은 결정론으로 넣는다. 근로소득세는 1인 가구(본인 1명)로 가정해 계산하고 "부양가족이 있으면 소득공제·세액공제가 늘어난다"를 붙인다.
- 판정·계산의 권위는 코드에 있다. Solar 는 계산 결과(trace)를 받아 문장만 쓴다. 계산 함수 안에서 LLM 호출 금지(Upstage 포함).
- 되묻기는 "결과를 바꾸는 질문 최대 2개". 총급여가 없으면 그것 1개만 묻는다.

작업 (로드맵 §4 R2 그대로)
- R2-a backend/calc/income_tax.py (새 패키지, 순수 함수)
  - 순서: 근로소득 → 근로소득공제 → 인적공제 → 연금보험료·4대보험 → 과세표준 → 기본세율(누진공제) → 근로소득세액공제(한도) → 지방소득세 10% → 결정세액.
  - 입력은 dataclass, 출력은 단계별 trace(단계 이름·값·근거 조문번호).
  - 표 값(공제 구간·세율·한도)은 laws.articles 현행 원문과 대조해 상수로 둔다. 소득세법 §47·§50·§51의3·§55·§59 등.
    조회: api/law_select.py 의 DbLawStore.get((법령명, 조번호))  (Article.no 는 "59", "51의3" 형식)
    대조 결과는 테스트 주석에 조문번호로 남긴다. 2026 적용분과 개정 예정분이 다르면 version 으로 구분한다.
  - 단위 테스트: 국세청 간이세액표·모의계산 사례와 교차 확인. 수치는 공식 자료에서만 가져온다.
- R2-b 슬롯 정의: 필수(총급여) / 기본값 있는 입력(부양가족=본인1, 공제=4대보험만, 자녀 0 …) / 선택 입력.
  기본값을 쓴 슬롯은 "가정" 문장으로 결정론 삽입한다.
- R2-c 파이프라인 연결(api/pipeline.py run_clinic):
  - tax_topic == "근로소득세·연말정산" 이고 총급여가 있으면 계산한다.
  - Writer 에 trace 를 넘긴다 → "가정 ○○으로 계산하면 …" + 단계표 + 결과를 바꾸는 질문 최대 2개.
  - 숫자 출처 = trace. numeric_guard 의 sources·derive_from 에 trace 를 넣는다. 안 넣으면 계산값 문장이 지워진다.
  - 총급여 추출: 추출 도구 스키마(engine_adapter.build_extraction_tool)에 필드를 추가한다. "연봉 5000"·"월급 400만원" 같은 표기를 확인할 것 — numeric_guard 가 "연봉 4천"을 못 읽은 전례가 있다(Y02).
  - outcome 은 새 이름(예: calc)으로 남긴다. rag.chat_turns.outcome 에는 CHECK 가 없다.
- R2-d 화면: 계산 단계표 블록(calc_breakdown).
  - ⚠️ 프론트 uiBlockSchema(frontend/lib/conversation-schema.ts:74)는 discriminatedUnion 이다. 모르는 kind 가 오면 응답 전체가 파싱 실패한다. 반드시 프론트를 먼저 배포한다.
  - 프론트 UI 는 팀장 프로토타입 영역이다. 블록 모양·위치는 바꾸기 전에 나에게 확인받는다.
  - 새 블록 없이 세그먼트 텍스트로 단계표를 내는 방안도 비교해서 제안해줘.

완료 기준
- "연봉 5000인데 내년 소득세 얼마야" → 1턴에 가정을 명시한 계산값 + 단계표 + 조문 배지.
- 후속 "부양가족 2명" → 재계산.
- 계산값이 테스트 기대값과 일치.
- R0 세트에서 상투 문구 0 유지 · 경비 6/6 유지.
- 지연은 **갈래별** 악화 ≤ 1초(R1 에서 재정의). 계산 갈래는 새 갈래라 자문 갈래 수준(7~11초) 안이면 된다.

측정
- 기본(운영): cd backend && .\.venv\Scripts\python.exe -m eval.run_demo_eval --tag <이름>
  일부만: --only W01,W02,W03,W04,W05,Y01,Y02
- 로컬 서버: env 로 넘겨 띄운다 — RAG_SOURCE=kb3 LAW_SELECT=on LAW_ONLY=on BACKGROUND_JOBS=off

- 같은 시나리오를 운영에서 2회 이상 돌려 흔들림을 본다. Solar 추출·검증은 temperature 0 이어도 흔들린다.

배포·작업 주의
