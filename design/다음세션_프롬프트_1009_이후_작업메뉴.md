## 6. 하지 말 것 / 함정

- **dev 서버가 떠 있으면 `frontend` 에서 `npm run build` 금지** — `.next` 를 덮어써 dev 가 깨진다(10/9). 빌드 확인은 dev 를 끈 뒤에, 아니면 tsc·테스트로.
- 로컬 `.env.local`·`backend/.env` = **운영** Supabase. 로컬 uvicorn 으로 챗 검증 금지. 운영 DB 에 시험 데이터 남기지 말 것.
- 사용자 확인 없이 서버 `.env`·배포·마이그레이션 금지.
- 새 정책에서 domain_id 로 세무사 쪽 권한을 줄 땐 `public.is_staff()` 를 붙인다(강등자 구멍, 0050). Realtime 정책 함수는 anon 실행권을 빼지 않는다.
- 그쪽(팀장) 파일 한복판에 live 조건문을 늘리지 말 것 — live 전용은 별도 파일·`services/*` 에.
- 로그인 화면은 소셜이 기본 — 이메일 칸은 "이메일 또는 기존 아이디로 로그인" 을 펼쳐야 보인다(Playwright).
