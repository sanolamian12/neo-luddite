## 착수 전 결정 (사용자)

1. **화면 자리 = `/admin/consultations` 탭 추가**(원안). 사이드바 메뉴를 늘리지 않는다.
2. **admin 은 대화 본문을 보지 않는다 — 집계만.** RLS(`consultation_messages_admin_read`)는 열려 있지만 화면이 안 그린다.
   사장님·세무사 사이 사적 대화이기 때문. 분쟁 대응이 필요해지면 그때 따로 설계한다.
3. **강제 조치 알림 없음.** 세 함수 다 당사자가 한 것과 결과가 같고, 가는 메일에 "운영자가 했다"는 표시가 없다.
   알리려면 메일 kind·사유 컬럼이 필요해 **DB 변경 → 범위가 바뀐다.** 대신 브레이크마다 화면 안 확인 단계(`ConfirmAction`)를 뒀다.
4. **열람 기록은 사례별·세무사별 둘 다.** 사례별 = 이 사례가 누구에게 열렸나(유출 추적), 세무사별 = 이 세무사가 얼마나 뒤지나(과열람 감시).
