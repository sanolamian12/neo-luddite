## 세무사 즉시 연결 (R3)

### 비로그인 → 간편 로그인 → 방 → 첫 인사 (10-12)
진단에서 live의 고객 흐름은 이랬다. 비로그인은 세무사 목록을 못 봤다. 로그인해도 신청 → 세무사 수락 → /consultations → 채팅방 열기의 5단계였다. 세무사 AI의 첫 인사도 없었다. e2e(`entry-response.spec.ts`)는 RPC를 모킹해서 이것을 잡지 못했다. → [DL](../8_결정교훈/DL_2026-10_W11_1011-1017.md)

| 붙은 것 | 내용 |
|---|---|
| 즉시 연결 세무사 카드 | 사장님 = '바로 연결하기' / 비로그인 = '간편 로그인하고 바로 연결' |
| 로그인 복귀 | `?c=…&connect=<id>`로 돌아와 자동 연결. `publicReturnPath`가 `c`·`connect` 외 쿼리를 지운다 |
| 방 도착 | `?arrive=1` → `LiveHandoffArrival`. 팀장의 데모 전환 장면을 live 데이터로 돌리고 데모 CSS를 재사용 |
| 첫 인사 | 도착하면 세무사 AI 첫 인사 API 호출(→ [BE](../4_백엔드인프라/BE_2026-10_W11_1011-1017.md)) |

화면이 " 세무사"를 붙이므로 `display_name`은 이름만 둔다(0055). 운영 E2E 결과는 → [EV](../7_평가검증/EV_2026-10_W11_1011-1017.md).
