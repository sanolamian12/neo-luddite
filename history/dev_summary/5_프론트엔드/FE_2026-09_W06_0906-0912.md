### CORS — 에러 없이 빈 화면 (09-11)
프로덕션 백엔드의 CORS는 `localhost:3000`만 허용한다(3001·3111은 400 "Disallowed CORS origin"). 3111로 띄웠다가 깔때기가 안 나왔다. 계측 복원 자리가 `.catch(() => {})`로 fetch 실패를 삼켜서 **에러도 없이 화면만 비어 보였다.** 컴포넌트 버그로 오진하기 쉽다. 로컬에서 프로덕션 백엔드를 보며 검증할 때는 반드시 3000이다.

저녁 세션에는 3000을 다른 프로젝트의 dev 서버가 점유하고 있었다. 남의 서버를 죽이거나 프로덕션 CORS를 고치는 대신 **로컬 CORS 프록시(3002) + 앱 3001**로 우회했다. 측정 대상이 CORS가 아니라 UI 경로라 이 우회는 검증의 의미를 바꾸지 않는다.

### '기타' 실사용 6고리와 Playwright 함정 둘 (09-11)
트리 표시 → 문장 카드 111개 → 이동 후보에 '기타' 자신 없음 → 이동 실행(111 → 110) → 이력 v1 `system_unsorted` → v2 `moved` → **이동 후 자기 질의에 1위 0.937**까지 확인했다. 이 이동은 세무사 계정으로 로그인한 **Playwright 자동화**가 한 것이다. 상세는 → [EV](../7_평가검증/EV_2026-09_W06_0906-0912.md).

함정 둘을 밟았다.
- 하이드레이션 전에 `fill`하면 값은 들어가도 React state가 비어 제출 버튼이 계속 disabled다. 타이핑 후 버튼 활성을 기다려 해결했다.
- `router.replace`는 클라이언트 라우팅이라 `waitForURL`의 load 대기가 안 풀린다. `waitForFunction(location.pathname…)`으로 해결했다.
