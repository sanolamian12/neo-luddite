# 프론트엔드 엔지니어 — W07 · 2026-09-13 ~ 09-19

> **이번 주 요지** — 프론트의 주 무대는 **AI 상담 규범 화면**이었다. 세무사가 AI의 시스템 프롬프트(L0 규범)를 화면에서 읽고, 초안을 쓰고, 확정하게 했다. 하루 뒤에는 그 위에 공개 → 이의 기간 → 승인·이의 → admin 거부·롤백의 흐름과, 로그인 직후 팝업 + 사이드바 배지를 얹었다. 쓰기 요청에는 Supabase 세션 토큰을 붙이기 시작했다. KB2 쪽에서는 기존 대목을 재사용한 정상 회차가 "실패했습니다"를 띄우던 판정을 고쳤다. 나머지 날은 일부러 **프론트를 건드리지 않았다.** KB2 접기는 기존 단계명 안에서 돌렸고, 코퍼스 분포 필드는 Zod `.passthrough()`로 그냥 통과시켰다. 둘 다 Vercel 배포가 딸려 오지 않게 한 선택이다.

용어 — **L0 규범**: 모든 답변의 작문 프롬프트에 상시로 붙는 규범 md 3종(master·frameworks·pitfalls). 이번 주에 DB(`norms.*`)가 원본이 됐다.

- 해설 시드(`/audit/knowledge`, `kb-store.ts` localStorage)는 건드리지 않았다. 사람이 읽는 해설과 AI가 따르는 규범은 다른 문서다.

### P6 — 토큰, 공개 제안, 알림, admin 브레이크 (09-17)

| 붙은 것 | 내용 |
|---|---|
| `lib/api-fetch.ts` | **쓰기 요청에만** Supabase 세션 토큰을 붙인다. GET은 preflight를 피하려고 붙이지 않는다. norms·kb2·rag 서비스에 적용 |
| `PendingProposal` | 공개 중 제안 카드 — 기한, 승인 n/N, 이의 목록, diff. 승인 / 이의 / 철회 / 수정 / 거둬들이기 |
| 공개 다이얼로그 | 초안을 공개(이의 기간 1일 시작) |
| `lib/norms-pending.ts`(zustand) + `NormsPendingWatcher` | 감사 셸에서 60초 폴링. sessionStorage로 **제안당 1회** 로그인 직후 팝업. 규범 화면에서 바뀌면 store를 즉시 갱신 |
| 사이드바 "AI 상담 규범" 배지 | 공개 중 제안을 알린다. 브라우저 시나리오에서 auditor2가 승인하자 배지가 사라졌다 |
| admin 모드 | 공개 중 제안 [거부](사유), 확정본 메타의 [직전 확정본으로 롤백] 다이얼로그(diff·사유 필수), 이력에 "거부된 제안"과 admin 사유 |

- 알림 방식은 PO가 "로그인 직후 팝업 + 사이드바 배지"로 정했다. 대시보드 카드와 메일 발송은 채택하지 않았다.
- 배포 순서가 중요했다. 백엔드가 토큰을 "검증하되 없으면 통과"로 먼저 나간 뒤 프론트 main을 올렸고, 그다음에야 토큰 필수로 바꿨다. 구 프론트가 깨지는 창을 없앤 순서다. → [BE](../4_백엔드인프라/BE_2026-09_W07_0913-0919.md)
- 브라우저 테스트는 먼저 화면 문구로 "새 빌드인가"를 확인하고, 아니면 **변경 없이 중단**하게 짰다. Vercel 반영을 기다리는 동안 옛 UI로 절반만 실행되는 사고를 막으려는 것이다.

## KB2 화면

### 자동 그룹화 성공 판정 (09-16)
- 성공 판정을 `groupsCreated`에서 `documentsGrouped`로 바꿨다. **기존 대목을 재사용한 정상 회차가 "실패했습니다"를 띄우고 있었다.** 생성 0이면 실패로 읽던 코드였다. 재사용이 오히려 바람직한 결과다.

### 일부러 건드리지 않은 자리 (09-13, 09-18)
- **KB2 접기·리필(09-13)** — 프론트는 job `stage`를 레이블 맵으로 표시한다(`kb2-synthesis-view.tsx`). 새 단계를 만들면 Vercel 배포가 딸려 오므로, 접기는 기존 `merging_categories` 단계 안에서 돈다. 프론트 변경 0.
- **근거 코퍼스 분포(09-18)** — `ChatMeta`에 `ragCorpora`/`ragPassages`가 새로 생겼지만 프론트 `chatMetaSchema`가 `.passthrough()`라 변경이 필요 없었다. 모르는 필드를 Zod가 지우는 함정에 걸리지 않는 자리다.
- **혼잡 안내(09-18)** — 게이트가 HTTP 200으로 안내 문장을 돌려주게 한 이유가 프론트에 있다. `services/chat.ts`는 비정상 status를 오류로 던진다. 200이면 평범한 말풍선으로 보인다. → [BE](../4_백엔드인프라/BE_2026-09_W07_0913-0919.md)
