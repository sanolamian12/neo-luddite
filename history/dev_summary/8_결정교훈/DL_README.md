# 8. 결정 · 교훈 (공통)

## 무엇을 정리하는가

**"무엇을 정했고, 무엇을 배웠나"의 기록이다.** 특정 포지션이 아니라 모든 포지션에 걸친 공통 섹션이다.
나중에 "왜 이렇게 되어 있지?"라는 질문이 나오면 여기서 답을 찾는다.
새로 들어온 팀원이 **같은 지뢰를 다시 밟지 않게** 하는 곳이기도 하다.

포지션 문서에는 결정의 결과만 한 줄로 남는다. 본문은 여기에 있다.

## 담는 것

### 결정
- **PO 확정** — 정책, 범위, 운영 규칙을 대표가 정한 것
- **구현 판단** — 설계를 어떻게 가를지 엔지니어가 정한 것
- **뒤집힌 결정** — 무엇을 무엇으로 왜 바꿨나
- **기각한 대안** — 왜 그 길로 가지 않았나

각 항목에는 **무엇을 · 왜 · 기각한 대안 · 누가(PO 확정 / 구현 판단)** 를 적는다.

### 교훈 — 밟은 지뢰
각 항목에는 **무슨 일이 있었나 · 왜 조용했나(화면·테스트·채점이 왜 못 잡았나) · 어떻게 잡았나 · 이제의 규칙** 을 적는다.

이 가운데 반복될 만한 교훈은 Claude 메모리(`MEMORY.md`)의 "함정" 줄로 올라가 있다.
이 폴더는 그 규칙들이 **언제, 어떤 사고에서** 생겼는지를 시간순으로 보여 준다.
