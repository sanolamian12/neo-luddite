# 프로덕트 오너 — W11 · 2026-10-11 ~ 10-17

> **이번 주 요지** — 개발의 기준이 바뀐 주다. 주 앞쪽은 데모 대비 로드맵(R0~R6)의 순서를 따랐고, 10/13부터는 **결선 보고서에 쓴 약속**이 기준이 됐다. 보고서 수치(출처 표시율, 법령 선두, 유형 분류, 형식, 지연)를 개발이 지켜야 하는 계약으로 다뤘고, 배포마다 자동 판정했다. 바깥에서는 실제 세무사의 평가가 두 번 들어왔다. 10/10 밤 피드백(4문항)과 10/14 2차 재평가 회신이다. 2차 회신의 "오히려 퇴보"(Q3 2/2/2)는 하루 오전 안에 반영됐다. 결정은 대체로 **범위를 좁히는 쪽**이었다. 표 카드 대신 텍스트 단계표, 비로그인 방 연결 대신 간편 로그인, 실제 세무사 대신 가상 세무사만 즉시 연결, KB2는 삭제했다.

## 결선 보고서 약속 이행

### 보고서 수치를 개발의 합격선으로 (10-13 ~ 10-15)
10/13부터 개발은 결과보고서 약속 이행 개발지침을 따랐다. 지침의 약속 번호(A1~A6)와 장부 항목(P2·P3·P11 등)이 일의 이름이 됐다. 배포할 때마다 데모 세트 2회 162턴을 돌리고 `report_check`로 보고서 수치를 자동 판정했다.

| 약속 | 내용 | 이 주의 결과 |
|---|---|---|
| A1 | Solar Pro 4로 운영(보고서 1.6 ④·2.2 ④) | 10/13 운영 전환 |
| A2 | 질문 유형 분류 | 95.9% |
| A3 | 유형별 답변 형식 | 세무사 문항 20/20 |
| A4 | 근거 서열(법령 선두) | 100% → 결론 먼저 뒤 새 정의 98.9% |
| A5 | 위임 시행령 | 합격 기준 충족(위임 질문 5문항 이상) |
| A6 | 3턴째 되묻기 | 0 |

이 주 PO가 내린 판단은 넷이다.
- **경비 되묻기·판정에도 근거 조문 배지**를 붙인다. 출처 없는 37턴 중 22턴이 경비 되묻기였다. 보고서에 이 사실을 밝힌다. → [DL](../8_결정교훈/DL_2026-10_W11_1011-1017.md)
- **A2 유형 라벨은 내부 제작**이라고 보고서에 밝힌다.
- **A6는 현행 문구를 유지**하고 D3·D4(9월에 정한 "모르겠어요" 처리와 되묻기 상한)를 원고에 이식하지 않는다. 원고의 해당 행이 이미 계산·판정 도구 문맥이라서다.
- 복합 사안 골격(E단계)은 **보고서에 쓰지 않은 시연 전용 항목**(장부 P11)으로 둔다.

열린 결정이 하나 남았다. 보고서 A2 문구는 "라우터 5유형 + 도구 선택"인데, 구현에서 유형은 답변 형식에만 쓰인다. 원고 문구를 고칠지 다음 버전(10/24~29)에서 구현할지 정해야 한다.

## 세무사 대응

### 10/10 밤 피드백 — 전부 추천안 (10-10 ~ 10-12)
세무사가 4문항 엑셀로 피드백을 보냈다. 대응은 **전부 추천안**으로 정했다.

| 피드백 | 대응 |
|---|---|
| Q1 세율표가 없다고 답함 | F1 법령 표 복원 — R3 앞에 |
| Q2 계산이 안 나옴 | F0 계산 라우팅 핫픽스 — 즉시 |
| Q3·Q4 요건 넘버링·법령 우선 서열 | R4 재정의로 흡수 |
| 재평가 | F0+F1 뒤 |

재평가 요청 문서(안내 docx + 답변분석 양식 xlsx)를 만들어 사용자가 보냈다. 피드백이 드러낸 것은 둘이다. 하나는 법령 DB에 표가 없다는 것, 다른 하나는 계산 라우팅 회귀다. 둘 다 → [DL](../8_결정교훈/DL_2026-10_W11_1011-1017.md).

### 2차 재평가 회신 — "오히려 퇴보" (10-14)
2차 점수는 이랬다.

| 문항 | 점수 |
|---|---|
| Q1 | 3 / 2 / 4 |
| Q2 | 4 / 3 / 4 |
| Q3 | **2 / 2 / 2 — "오히려 퇴보"** |
| Q4 | 3 / 2 / 2 |

지적 1~5(결론 먼저, 사례 자료, 반복, 법령만 답의 선두 문구, 정의 깊이)를 그날 오전에 반영해 운영에 올렸다. 지적 6(형식 — 계산 산식 표, 비교표, 요약)은 B단계로, 3차 평가 요청은 D단계로 순서를 잡았다. 반영 상세는 → [AIE](../2_AI엔지니어/AIE_2026-10_W11_1011-1017.md) · [KE](../3_지식엔지니어/KE_2026-10_W11_1011-1017.md).

같은 날 오후 팀 피드백으로 화면 방향을 바꿨다. 법령 접기는 보류하고 **산문 + 표 + 결론 문단**으로 보인다. 이 표시 방식은 사용자 설정이 아니라 코드 상수다. → [FE](../5_프론트엔드/FE_2026-10_W11_1011-1017.md)

### 세무사 자료와 3차 평가 (10-14 ~ 10-15)
- 세무사가 10/14에 캡처(비상장주식 아들 저가양도)를 보냈다. 이것이 복합 사안 골격(E단계)의 첫 사례가 됐다.

- 3차 평가 원문(운영 재현 12턴)을 준비했다. 발송은 사용자가 한다. 발송 시각을 로드맵 진행 기록에 적으면 **규칙 8**(평가 요청부터 회신까지 답변 경로는 운영 배포 보류)이 시작된다. → 이어서: 3차 회신 반영과 규칙 8 구간 종료 (W12)
