# 지식 엔지니어 — W13 · 2026-10-25 ~ 10-31

> **이번 주 요지** — 증여 계산 갈래의 **세법 근거를 운영 법령 DB 원문에서 하나씩 확인**했다. 확인이 곧 범위가 됐다. 시행령 §46의3②(세대생략 + 합산 할증 계산식)는 DB 원문에 수식이 없어서 조부모 증여 + 합산은 계산하지 않기로 했다. 시행령 §159①(부담부증여 취득가액·양도가액 안분)도 DB 원문에 식이 없었다. 원문이 PDF 이미지였기 때문이다. 이번에는 법령 API 캐시의 상자 문자에서 `X = A × B ÷ C` 꼴로 **식을 복원해 적재**했다. 적재 도구가 jsonl 전체를 DB와 비교해서, 10/15에 복원해 둔 조특법 2행이 같이 들어갔다(무해).

## 적재

### 시행령 §159① 식 복원 (10-26)
- **무엇이 없었나** — DB의 §159① 원문에 계산식이 없었다. 법령 원문에서 식이 PDF 이미지였기 때문이다.
- **어디서 찾았나** — `data/laws/api_cache/소득세법_시행령.json`. 식이 상자 문자로 그려져 있었다. 이것을 `X = A × B ÷ C` + A·B·C 설명 줄로 복원했다.
- **같은 조문인가** — 공포번호는 DB 36343 / API 36737로 다르지만 조문 본문은 같았다.
- **적재** — 사용자가 `law_ingest.py ingest`를 실행했다(3행). ingest는 `articles.jsonl` 전부를 DB와 비교한다. 그래서 10/15 표 복원분인 조특법 2행이 같이 들어갔다(무해).
- 그다음 push → 배포 순서였다. → [BE](../4_백엔드인프라/BE_2026-10_W13_1025-1031.md)

10/15의 표 복원과 같은 계열의 일이다. **법령 DB에 이미지로만 있던 내용**을 API 원문에서 되살려 적재했다.
