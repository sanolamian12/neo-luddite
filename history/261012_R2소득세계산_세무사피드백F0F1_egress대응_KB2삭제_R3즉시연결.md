## 3. 진단에서 알게 된 것

- **laws.articles 에 표가 통째로 없었다.** 법제처 PDF 의 표는 **이미지**라 텍스트 추출에서 빠졌다(현행 약 276조 휴리스틱). 소득세법 §47①·§55①·§59① 등. LLM3 가 §55 를 맞게 골라도 작문이 숫자를 못 쓰고, 재현에서는 "현행 조문에는 세율표가 포함되어 있지 않다"는 틀린 말까지 했다(세무사 Q1). **국가법령정보센터 Open API 본문엔 같은 표가 상자 문자(┌─┬)로 원문 텍스트로 있다.**
- **세무사 Q2(계산 없음)는 내 회귀였다.** G01 수정(프리랜서 질문이 계산 갈래로 샘)에서 '종합소득세'를 비근로 신호로 넣었는데, 근로자도 관용적으로 "제 종합소득세는 얼마인가요?"라고 묻는다. 계산 함수 자체는 맞았다(4대보험 0 조건 3,148,750원 = 세무사가 "더 정확하다"고 한 클로드와 동일).
- **세무사는 한 대화에 세목이 다른 4문항을 이어 물었다** → 대화 전체를 훑는 라우팅은 앞 질문 낱말이 뒤 질문을 막는다. 판단은 이번 발화(짧은 답이면 직전 발화까지)로.
- **추출 30초 타임아웃 500 4건이 전부 3·4턴째** — 긴 이력(계산 답 20문장 등)이 추출을 느리게 한다.
- **Supabase egress 293%(14.63/5GB)의 원인 = `vec_memory`**: 재시작마다 4096차원 벡터 전량(법령 7,613 + KB3 5,101행)을 텍스트로 받아 1회 674MB. 배포 restart 와 로컬 uvicorn 이 원인 — **이 로드맵 세션의 로컬 서버도**(`LAW_STORE=file` 로 띄워도 vec_memory 는 운영 DB 에서 받는다) 원인 제공자였다.
- **프롬프트 예시가 날조 인용이 됐다.** LAW_RULES 의 "사례는 문서번호(예: 조심 2024서0560, 서면-2022-원천-4266)로만" 예시를 Solar 가 실제 사례처럼 옮겨 적었다(증여세율 답).
- **live 에서 비로그인은 세무사 목록조차 못 봤다.** `list_experts` 가 authenticated 전용 + `me.id is not null` 필터. e2e(`entry-response.spec.ts`)가 RPC 를 모킹해서 드러나지 않았다. 신청 → 세무사 수락 → /consultations → 채팅방 열기 5단계, 세무사 AI 첫 인사 없음.
- 사장님 DB 역할은 **`'user'`**(viewer 는 프론트 이름). `auditors.display_name` 은 **이름만**(화면이 " 세무사"를 붙인다). `publicReturnPath` 는 `c` 외 쿼리를 지운다.

### 4.1 R2 근로소득세 계산 (`backend/calc/`)

## 6. 함정 (다음에 또 밟지 말 것)

- **로컬 백엔드는 `VEC_MEMORY=off` 로만** 띄운다(디스크 캐시가 있어도 `--reload` 연속 재시작 중엔 쓰다 만 캐시로 다시 받을 수 있다). 배포는 모아서.
- 법령 표는 **API 원문**에서 — PDF 는 표가 이미지다. 표가 바뀌면 `law_tables_api.py apply` → `law_ingest.py embed` → `ingest`(사용자) → 재시작 1회(지문이 바뀌어 캐시 갱신).
- 계산 라우팅에 세목 이름('종합소득세')을 비근로 신호로 쓰지 말 것. 판단은 이번 발화로.
- 프롬프트 예시에 실제처럼 보이는 문서번호·수치를 넣지 말 것(그대로 인용된다).
- 숫자 파서는 `numeric_guard` 말고 `calc/income_tax_extract`("연봉 4천"·"1인 가구"의 1 함정).
- 테스트 체인은 `cmd; tail` 로 이으면 실패해도 다음 단계가 돈다 — 실제로 테스트 1개 실패 상태로 배포·커밋이 나갔다(로직은 정상, 기대값 오기).
- 셸 `python` 은 backend/.venv 가 PATH 앞(시스템 파이썬은 `AppData/Local/Python/bin/python`). Node 는 Git Bash `/tmp` 를 못 찾는다.
