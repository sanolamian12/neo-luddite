## 4. 하면서 알게 된 것 (설계 본문에 반영함)

1. **① 검색은 선고일자순** — 관련성 순위가 없다. 본문 검색이라 "연말정산"이 어디 한 줄에만 나와도 걸린다. 제목 적중 우선 정렬을 넣었다.
   증거: 재개 테스트에서 `--max-pages 1` 로 돌리자 첫 쪽(제목 적중 0)에서 **횡령 사외유출·출국 거주자** 사건 5건을 받아 왔다 → raw 에서 걷어냄.
2. **상한이 "이번 실행" 기준이면 재실행 때 더 받는다** — 위 5건이 그것. raw 누적 기준으로 고쳤고, 재실행 시 새로 받는 건 0 확인.
3. **세목은 관련 법령보다 코드(`ntstTlawClCd`)** — 관련 법령은 5/20 이 비어 매핑 75%(기준 80% 미달). 코드 303/305/307/308 을 제목으로 읽어 매핑하니 100%.
   단 17개 세목이 병의원 지출 관점이라 법인세 → '기타', 양도·연말정산 → 전부 `소득세·법인전환·개원폐업`.
4. **링크는 ② Location 이 `/qt/`**(20/20). 설계의 `/pd/` 도 200 이지만 law.go.kr 가 실제로 준 주소를 쓴다.
5. **요지에 `<br />`** — 정리본에서 공백으로.
6. **"병의원"은 키워드로 쓸모없다** — 걸린 5건: 현물출연 기부금·거래처 상여처분·의약품 리베이트(법인세 3) + 농지 직접경작 감면 1·2심(요지 속 "수도권 병의원을 이용"이 거주 판단 근거). 병의원 쪽은 의료업·요양급여 등으로.
7. **연말정산 5건 = 전부 "부과제척기간 5년"** — 1심·2심·대법 심리불속행 사슬. 시민이 묻는 연말정산(의료비·월세 공제)과 판례가 다투는 연말정산은 다르다. 판례는 분쟁이라 **공제 요건 같은 일상 질문은 판례보다 질의회신(예규) 쪽이 맞을 수 있다** — 범위 밖이라 열린 질문으로만 남긴다.
