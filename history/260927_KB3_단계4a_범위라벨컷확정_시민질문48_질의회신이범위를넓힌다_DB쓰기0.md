## 4. 알게 된 것

1. **판례는 같은 갈래에서 질의회신에 밀린다** — 요지 중앙 120자라 코사인이 낮다. 0.45 에선 0회, 0.40 에서 158문항 중 10회(등급2 4). 판례를 따로 부르려면(W5 가 "법원 판단" 층을 원하면) 갈래를 나누거나 코퍼스별 컷이 필요하다.
2. **걱정한 혼입은 없었다** — 사해행위취소 민사는 0회. 병의원 쪽 잡음은 "같은 분야 다른 쟁점"(외국납부세액공제 → 한·러 조세조약 회신, 임원상여 → 임원퇴직소득 원천징수 가산세).
3. near −1문항 = kb3 가 kb2/rag 자리를 하나 가져간 것. 채점 흔들림은 같은 갈래끼리 ±2pp.
4. 질의회신 `full_text` 는 **회신만**이다(요지 미포함) → 본문 = `요지: … \n회신: …`.
5. 판례 요지 최대는 1,149자(설계의 429자는 파일럿 기준).
