## 2. 세무사 대조 설계 (9/14)

ICTC 대조의 형식을 이어받되 두 가지를 고쳤다.

| 항목 | 내용 |
|---|---|
| 표본 | `verify/draw_sample.py`, **시드 20260914로 미리 추출**. LLM 가짜 판정 20(off 8 · rag@0.50 4 · kb2@0.35 4 · rag@0.35 4) + 정상 판정 10(4·2·2·2) |
| 맹검 | LLM 판정은 `_KEY_sealed.json`에 봉인하고, 세무사에게는 대조표·요청서만 전달(`verify/세무사_전달용/`). 순서는 무작위, 조건도 숨김 |
| ICTC 대비 개선 | ① **"인용 맥락(답변 발췌)" 열 추가** — 조문 번호만으로는 표제·내용 불일치를 못 잡는다 ② 판정 대응을 문자열이 아니라 **식별자 키**로 한다(법령명·조·의 / 연도·부호·번호) |
| 판정 | ① 실재 ② 표제·내용 일치 ③ 최종: 정상 / 표제불일치 / 부존재 / 확인불가 |

요청서는 md를 PDF로 바꿔 전달했다(세무사가 md를 못 열 것이라 판단).
