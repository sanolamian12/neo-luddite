## 무엇을 했나 (지적 번호 순)

1. **결론 먼저**: 근거 서열 작문 규칙을 "첫 설명 = 사용자 사안 직답(근거 조문) → 조문 설명"으로. 물은 것이 둘이면 '■ 물은 것: '으로 나눠 각각 결론부터, 사안의 결론 부분을 맨 앞에. 법령만 판 시스템 규칙 1("사안이 요건을 채운다고 단정 말 것")이 '제조업 = 배제 업종' 같은 조문 그대로의 결론까지 막고 있어 고쳤다. 긴 대화에서 앞선 답 모양을 따르던 것 → 작문 user 메시지 끝에 순서 한 줄. 끄기 `ADVISORY_CONCLUSION_FIRST=off`.
2. **사례 자료**: 정의 = 0건, 요건 = 게이트 'same' 1건, 세율 표가 나가는 답 = 0건(`_trim_cases_for_law`). 쟁점 게이트는 'different' 만 빼서 'related'(Q3 2020 다사업장 해석·증여세 가업승계 특례)가 다 들어오던 자리. 로컬에서 Q4 '간접외국납부세액' 질의회신은 게이트가 same 으로 봐서 정의는 0건으로 정했다. 끄기 `ADVISORY_CASE_TRIM=off`.
3. **반복 제거**: 결정론 표(세율) 수치 3개+ 겹치는 작문 문장·'다음과 같이' 머리말 제거(결론 문장도 5개+면), 호 목록을 다시 푼 문장(항목 2-gram 0.55+가 둘 이상, 또는 '제N호' 둘 이상) 제거. 요건 폴백(10/13): 요건 부분 조문부터 찾고, 시행령 인용이면 그 시행령이 받는 법률 조문의 호(§109② → §61①), '삭제' 호 제외, 요건 부분 뒤에 둔다. 확인할 사항 번호 목록(머리 '확인·알려' 또는 질문 꼴 절반 이상)은 요건 목록으로 치지 않고 앞 조문 배지도 물리지 않는다. 끄기 `ADVISORY_DEDUPE=off`.
4. 법령만 답 선두 "이 질문을 직접 다룬 심판례·국세청 해석은 찾지 못해" → "아래는 현행 법령 조문을 바탕으로 한 참고 안내입니다(세무사가 이 사안을 확인한 내용은 아닙니다)."
5. **정의 깊이·A5**: 정의·요건 유형은 고른 법률 조문을 첫머리에서 "법 제N조"로 받는 시행령 조문 1개를 결정론으로 보탠다(`law_select.delegated`, 세율 질문 제외 — §55 에는 근속연수 같은 잡음이 붙는다). 조문 상한 900 → 1,800자(`ARTICLE_CHARS_DEEP`). Q4: §15 → 시행령 §11(수익 범위 전문) → §18 익금불산입. 정의 형식 규칙에 '범위·제외' 줄. 끄기 `LAW_DEEP=off`.
