## 3. 진단에서 알게 된 것

- 권한 판정이 둘로 갈려 있었다: **역할 기준**(원문 열람·수락·제안·풀·카드·스위치·에이전트·백엔드 쓰기)은 role 만 바꾸면 끊기지만,
  **domain_id 기준**(방 읽기·**메시지 쓰기**·자기 앞 신청/제안·검수 CRUD·코멘트·평가·리뷰·이의)은 남는다 → 강등자가 열린 방에 "세무사"로 글을 쓸 수 있었다.
- 강등자는 회원 화면이라 우편함이 없다 → 알림은 신청서 상태 `revoked` + 사유로.
- 0049 승인은 auditors 행이 있으면 실패 → 재승인 분기 필요.
- 탈퇴 경로 구멍: `expert_agents` 는 auth FK 없음(고아), `kb3.documents.expert_id` 는 set null(공용 승인 사례가 이름째 남음).
