## 3. C단계 — 이번 턴의 성격

- 추출 스키마 `turn_kind` enum: 답변 / 같은 주제 / 다른 주제(출력 +4토큰). 끄기 `TURN_KIND=off`.
- `_settle_turn_kind`: 첫 턴 None · 질문 꼴(`_QUESTION_FORM`)이 아니면 모델 값과 무관하게 '답변'(짧은 답을 새 주제로 읽으면 맥락 전부를 잃는다).
- 답변 턴 + 앞 주제가 경비 아닌 특정 세목(근로·종소·부가·양도·상속증여·인건비·법인전환·조사) + etype 이 경비 유형 + 경비 낱말 없음 → etype=기타 · 주제 유지 · 검색 질의 = `앞 주제 + 직전 질문 + 이번 답`(검색 질의를 안 고치면 S02 2턴이 주택임대소득 조문으로 답했다).
- 다른 주제 → 판정·계산 입력값 버림(금액은 이번 발화에 수가 없을 때) · 이력 없이 답 · 끝에 "더 다양하거나 깊은 질문은 새 상담을 시작하시거나 세무사와 상담해 보시길 권해 드려요." + 세무사 박스(reason `topic_shift`). 3자 방은 제외.
- 운영 c1·c2: 다른 주제 = X05 3·4턴만(4/4회), 오판 0. X05-3 결론 문단 첫 문장에 '제조업 = 시행령 §109②2호 배제'.
