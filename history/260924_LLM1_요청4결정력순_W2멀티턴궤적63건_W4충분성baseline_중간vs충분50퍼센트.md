## 3. W4 — 충분성 판정 하니스 + baseline

| | zeroshot | fewshot | 길이 오라클 |
|---|---|---|---|
| 전체 | 70.5% | 74.3% | 86.3% |
| **중간 vs 충분** | **50.0%** | **50.0%** | 72.0% |

| 충분 재현율 | 4.8% | 1.8% | |

- **모델이 "충분"이라고 말하지 않는다.** fewshot 전체 74.3% = 평가셋 불충분 비율 74.3% — 전부 불충분 찍기와 동일.
  진짜 지표는 우연 수준이고 길이 규칙보다도 낮다. few-shot 이 충분 재현율을 오히려 낮춤.
- 과잉 되묻기: 누락 사실 중앙값 4~5개(정답 1~3), 반복 퇴화로 600토큰 잘림 14~37건. solar-pro3 는 `missing_facts`
  를 `sufficiency` 앞에 써서 잘리면 판정값이 없다 → "잘림=불충분 간주" 민감도 줄을 병기(결론 동일).
- **로드맵 §4 함정(멈출 줄 모르는 LLM1 → STALLED 로 세무사 연결 누출)의 실측.** D4 상한은 안전장치로 필수.
