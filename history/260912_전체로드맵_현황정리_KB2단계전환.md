## 0. 한 문단 요약

로드맵은 **두 계층**이다. 계층 1(원본 RAG `rag.passages`)은 **끝났고** 남은 건 규모
모니터링뿐이다. 계층 2(KB2)는 **기능 1~19 를 전부 만들어 배포했고**, 그래서 지금은
"더 만들 것"이 아니라 **"이게 실제로 작동하고 자란다는 증명"** 단계로 넘어갔다.
그 기준이 G1 재현성 / G2 축적성 / G3 임팩트다. **G1 은 값 결정 하나만 남았고, G2 는
2026-09-12 에 성립했고, G3 는 미착수 — 남은 가장 큰 덩어리는 G3 다.**

## 2. 계층 2 — KB2 (로드맵 §7): 기능 빌드 완료

**동기**: 번들 전체(질문+답변+코멘트)를 통짜로 임베딩하면 조항형 지식이 길어질수록
희석된다. KB2 는 Solar Pro 가 이를 **문장(조항) 단위**로 응축·재구성한 별도 정책 사전 —
검색·크레딧·수정이력의 최소 단위를 문서에서 문장으로 낮춘다. 기존 RAG 경로는 한 줄도
안 건드리고 완전 병렬로 얹었다(`?ragSource=rag|kb2|hybrid`).

**로드맵 1~19 전부 완료·프로덕션 배포**:

```
 1~3  스키마 · 합성 트리거 · 검색 A/B 전환
 4    auditor 문장 직접 수정 (locked_by_auditor)
 4.5  AI 동적 카테고리 재구조화 (17개 고정 세목 폐기)
 4.6  2단 트리(대목/세목) · 문장 이동 · 편집 락
 5~10 미분류 자동 대목 배정 · 롱프레스 버그 · UI 개편 · 야간 배치 · 연결끊기/재연결
11~13 최초 실제 실행 · 호출 상한 · stale job 회수 · 커버리지 원인 규명 · 계측 도입
14    합성 인용 누수 → 인용률 59% → 96%
15    나쁜 회차 가드 + "회차 붕괴"의 정체 규명
16    merge 하한 A/B/C 실험 → 원인은 목차가 아니라 **분류 입력** → 커버리지 52% → 64%
17    '기타' 세목 + 합성 단계 가드
18    합성 회차 편차 최초 측정 → 하락의 정체는 **타임아웃**
19    세대교체 축적성(G2) — 보존 + 의미 기반 재부착   ← 2026-09-12
```

**여기가 전환점이다.** 더 만들 기능이 없어서, 남은 일이 "이게 실제로 작동하고 자란다"를
증명하는 쪽으로 성격이 바뀌었다. 이 전환을 놓치면 "커버리지 몇 %p" 같은 계기판 숫자를
목표로 착각하게 된다.

## 3. 완성 목표 G1 / G2 / G3 — 지금 위치

> 한 줄로: **"세무사가 하루 쓰면 KB2 가 그만큼 좋아져 있고, 다음 회차가 그걸 지우지 않으며,
> 지표가 편차 안에서 재현된다."**

| | 목표 | 상태 | 남은 것 |
|---|---|---|---|
| **G1 재현성** | 지표가 편차 안에서 재현 + 차이를 계측으로 분해 | **95%** | 합성 타임아웃 **값 결정** 하나 |
| **G2 축적성** | 사람이 손댄 것이 세대교체를 살아남는다 | **2026-09-12 성립** | 회차 쌓아 재평가 |
| **G3 임팩트** | kb2 경로의 되묻기율 ↓ | **미착수** | **남은 가장 큰 덩어리** |

### G1 — 거의 끝났다

계측이 값을 했다. 커버리지 63.9% → 59.3% → 66.3% 가 **분해되어 읽힌다**:
배정 변동은 분류 회차 편차 안(상대 3.6% < 측정 3.8%)이고, 인용 변동은
`synthesisLostChunks` 가 설명한다(유실 1청크 ≈ 커버리지 3%p).
**커버리지는 목표가 아니라 계기판이고, 자동 경로 천장 63~65% 에 이미 도달해 있다.**
숫자를 올리는 작업은 더 하지 않는다.

남은 하나가 **합성 타임아웃**이다. 분포는 2026-09-12 에 측정됐다(§4①).

### G2 — 2026-09-12 성립

재구조화가 활성 세대를 통째로 archive 해서, 세무사가 옮긴 문장이 **한 회차 만에
원상복귀**하고 있었다. KB 가 자라지 않고 **회차마다 다시 만들어지던** 것이다.
사람이 손댄 문장을 보존하고 **레이블 임베딩이 가장 가까운** 새 세목에 재부착하도록
바꿨다(임계값 0.70, 쌍 목록 171건을 전수로 읽고 첫 오탐 위에 그음).

실측(job `e6af3b47`): **보존 3/3 생존, 세목 유지 2/3.**

**정직하게**: G2 는 **"문장을 안 지운다"를 달성했고**, **"사람이 고른 세목을 지킨다"는
목적지 개념이 목차에서 통째로 사라지면 못 지킨다.** 실패 1건은 임계값 탓이 아니라
이번 세대 목차에 양도·비과세 계열이 **아예 없어서**였다(최고점 0.4605).
→ 재부착률은 **목차 안정성의 함수**다. 1회로 임계값을 건드리지 말 것.

### G3 — 미착수, 그리고 이게 제품 논지 그 자체다

제품 논지는 **"RAG 는 답변 품질이 아니라 '답할 수 있는 범위'를 넓힌다"**(판정은 엔진
권위라 안 바뀐다)인데, **kb2 경로에서 이게 숫자로 보인 적이 한 번도 없다.**
지금까지의 모든 작업(커버리지·축적성)이 이걸 위한 준비였다.

## 4. 남은 작업 3가지 (우선순위순)

### ① 타임아웃 값 결정 — G1 마감 (작음)

분포는 나왔다(job `e6af3b47`):
```
성공 48회: min 0.71s  p50 3.54s  p90 243.2s  max 248.3s
실패  1회: 480.7s ( = 240s × 2, SDK 내부 재시도 )
```
**"모델이 느리다"가 아니다** — 느린 생성이면 연속 분포여야 하는데 3.5초에서 **240초
벽에 딱 붙어** 두 덩어리로 갈라진다. 상한 = p50 의 **68배**. 정상 48회면 2.8분인데
실제 35분 → **호출 ~10% 가 벽시계 ~85%** 를 먹었다.

⚠️ 다만 **원시 소요 목록을 저장하지 않아 "벽 아래의 진짜 p90"을 모른다** — 상한을
낮출 때 정상 호출을 자르는지 판단할 근거가 아직 없다. 원시값 저장 한 줄 + 한 회차 더.
부수 효과: 재구조화가 35분 → 5분대가 되어 이후 모든 실험이 싸진다.

### ② G3 임팩트 실증 (큼) — 남은 진짜 일

kb2 경로의 되묻기율을 배선해 측정한다. ⚠️ **되묻기는 두 종류**이니 섞지 말 것:
- **선례 없음**(`ragHits=0` + `followUp=True`, `pipeline.py:109~121`) ← **G3 의 지표**
- **결정변수 부족**(판정형 ①-b, `pipeline.py:137~`) ← RAG 와 무관, 섞으면 지표가 오염된다

**3방향 벤치마크(무RAG / 기존RAG / KB2)는 논문 세션 사안**이다. 제품 세션에서는
kb2 경로의 되묻기율을 **계측으로 남기는 것**까지.

### ③ 트리 가독성 묶음 (중간)

근사 동의어 병합 — ⚠️ **접기만 하면 안 된다.** A/B/C 실험에 조건이 붙어 있다:
`B 접고 30개로 채움 = 53.6% ≈ A(중립)` vs `C 접고 22개로 축소 = 46.4%(나쁨)`.
**접은 만큼 리필해야** 커버리지 중립이고, 리필에 LLM 호출이 하나 더 붙는다.
같은 묶음: 보류된 "맵 입력 [질문]만"(+3.5%p) 재측정, 보존 문장과 신규 문장이 같은
세목에 나란히 보이는 것.

**이 3가지를 끝내면 KB2 개량 개발을 일단락한다.**

## 5. 그 다음 — 논문 연구 (ACK 2026)

KB2 개량이 일단락되면 논문으로 넘어간다. **ICTC 논문의 보완 연구가 아니라 새 학회에
낼 별도 논문**이다: **NO RAG vs 기존 RAG vs KB2** 3방향 비교로 KB2 의 효과를 입증해
**ACK 2026** 에 제출한다.

구조가 가능함은 이미 실호출로 확인돼 있다 — `?rag=` on/off × `?ragSource=rag|kb2|hybrid`
두 축이 직교한다. 제품 세션에서 미리 깔아두는 것은 G3 계측 배선까지이고, 벤치마크
설계·실행·채점은 논문 세션에서 한다(`docs/doing/HF_사용정책_국내AI트랙.md` §5).

**세션 분리 원칙**: 논문·연구와 제품 코드 수정은 다른 세션. 제품 세션에서는
`backend/api/` 런타임이 Upstage 전용이라는 국내 AI 트랙 조건이 그대로 적용된다.

관련: ICTC 2026 논문은 별건으로 채택됐고 **카메라레디 9/17 마감**(논문 세션 사안).
