## 무엇을 했나

- **A2**: 추출 도구에 `question_type`(계산·법령 정의·요건·사례 판단·절차·기타). 호출 추가 없음.
  - 이름만 주면 "~하면 부가세 내야 해요?"가 '법령 정의'로 쏠림 → 모델에 보이는 enum 값에 짧은 풀이(`사례 판단(해당 여부)` 등), 받은 값은 `normalize_question_type` 이 5유형으로.
  - 같은 문장도 회차마다 갈림(temperature 0) → 강한 어휘 단서는 결정론 보정(`pipeline._QTYPE_CUES`).
  - 되묻기에 대한 짧은 답("연봉 4천이에요")이 '계산'으로 바뀜(스키마에 금지 문구를 써도) → 질문 꼴이 아니면 같은 대화의 직전 유형을 이음(프로세스 메모리).
  - 라벨: 데모 세트 턴별 `qtype`(내부 제작 — 보고서에 그렇게 밝힌다). 과적합 점검으로 홀드아웃 2벌: 1(20문항, 설명 다듬기 중 봄) · **2(15문항, 단서 규칙 작성 전에 라벨 고정)** — 최종 데모 95.9% · 홀드아웃1 100% · 홀드아웃2 94.4%.
- **A3**: 작문 규칙의 '요건이면… 정의면…' 두 줄을 유형별 한 줄로(그 밖 유형은 형식 줄 없음). 결정론 마무리:
  - 요건: 한 문장 속 "1. … 2. …"·①② 분리 → 항목 세그먼트, 번호 다시 매김, 항목마다 호 단위 배지(`law_cite` 로 본문 인용 파싱, 허용 조문만). **작문이 목록을 끝내 안 쓰면**(X03 차이+요건 복합 질문 — 규칙을 넣어도 산문) 답이 먼저 인용한 조문의 호를 원문 그대로 번호 목록으로(`law_select.item_list`, 호 속 '다만,' 단서는 뺌) — 세율 표 F1 과 같은 근거.
  - 정의: '관련 조문:' 줄이 없으면 LLM3 가 고른 다른 조문으로 보충(첫 설명에 나온 조문 제외). 산문 속 '관련 조문과…'는 형식 줄로 안 친다.
  - `trim_answer` 겹침 계산에서 괄호 속 조문 제외(항목마다 같은 '(「○○법」 제N조제1항제K호)'), 요건 답 상한 10문장.
- **A5**: 위임 인덱스(시행령 머리의 '법 제N조…대통령령')로 후보를 넓히는 코드를 만들어 오프라인 A/B(`eval/a5_delegate_offline.py`) — off·on 모두 10/10 시행령 동반 선택 → 넣지 않음. 운영 a3_prod 에서 위임 질문 X03·Y03·G03·T02·Y01 2/2 회차 시행령 인용, 자문 46/92 가 시행령 인용 → 합격 기준(5문항 이상) 충족.
